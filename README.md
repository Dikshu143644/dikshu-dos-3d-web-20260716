# Dikshu

Dikshu is a cinematic luxury web experience by DOS. It combines immersive image sequences, smooth scroll storytelling, editorial gallery pages, and refined interaction details for a premium resort-style presentation.

## Brand

- Brand name: Dikshu
- Company: DOS
- Contact: reservations@dos.com

## Experience

- Full-screen animated landing experience
- Scroll-driven visual storytelling
- Suites and spaces selector
- Parallax gallery presentation
- Dining and contact sections
- Responsive Next.js interface

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lenis smooth scrolling

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
